=head1 NAME

  Math::GMP_OLOAD - assist in the overloading of Math::GMP objects.

=head1 DESCRIPTION

  This module allows Math-MPFR-4.43 and later to overload Math::GMP objects
  wrt all arithmetic and comparison operations.
  This module relies on Math::GMP being available, and will fail to load if
  Math::GMP cannot be loaded.
  YMMV if Math-MPFR is at an earlier version or if Math-GMP version is less
  than 2.11.
  It is planned that, in future, this module will be extended to also allow
  the extra overloading of Math::GMP objects with Math::GMPz and Math::GMPq.

=head1 SYNOPSIS

  Either:
  require Math::GMP_OLOAD;
  or:
  use Math::GMP_OLOAD;

  Example:
    use strict;
    use warnings;
    use Math::MPFR;
    require Math::GMP_OLOAD;

    # In actual fact, the low limit (unverified) might be less thn 4.43.
    die "Math::MPFR is untrustworthy" if $Math::MPFR::VERSION < 4.43;

    # In actual fact, the low limit (unverified) might be less thn 2.11.
    die "Math::GMP is untrustworthy"  if $Math::GMP::VERSION  < 2.11;

    my $g = Math::GMP->new(17);
    my $f = Math::MPFR->new(20.5);
    print ref($g), "\n";     # prints 'Math::GMP'
    print "ok\n" if $g < $f; # prints 'ok'
    $g *= $f;
    print ref($g), "\n";     # prints 'Math::MPFR'
    print "$g\n";            # prints 3.485e2
